# Teamdokumentation — börja här

Välkommen till Tullsyn. Den här mappen är skriven för dig som är ny i
projektet — utvecklare eller affärspartner — och vill förstå vad som byggts,
varför det ser ut som det gör och var du kan bidra.

**Läs i den här ordningen:**

1. **[projekthistorik.md](projekthistorik.md)** — berättelsen: hur projektet
   vuxit från skript till system, vilka beslut som fattats och varför,
   hur vi arbetar, och var det finns öppna trådar för nya perspektiv.
2. **[systemoversikt.md](systemoversikt.md)** — nuläget: vad systemet kan
   idag, modul för modul, kvalitetsläget och vad som medvetet väntar.
3. **[risker.md](risker.md)** — riskregistret: allt som behöver granskas,
   bevakas eller lösas innan/under skarp drift, sorterat per kategori.

**Vill du köra systemet direkt** — se [README](../../README.md) i projektroten
och [CLAUDE.md](../../CLAUDE.md) för arkitekturkartan. Alla designbeslut finns
dokumenterade som specar i [docs/superpowers/specs/](../superpowers/specs/).
